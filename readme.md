# ⏱️ Cronômetro

Um cronômetro simples e funcional feito com **HTML**, **CSS** e **JavaScript puro** (vanilla JS), sem frameworks ou bibliotecas externas.

## 🔗 Demo

[Acesse o projeto online](https://werthercrisley.github.io/cronometro)

## 📋 Funcionalidades

- ▶️ Iniciar contagem
- ⏸️ Pausar contagem
- 🔄 Zerar cronômetro
- 🕐 Exibição em minutos e segundos

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura da página
- **CSS3** — estilização e layout
- **JavaScript** — lógica do cronômetro (manipulação do DOM, `setInterval`)
